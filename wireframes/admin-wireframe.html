7. Admin User Flow Diagram

🚪 START — Admin opens /admin/login
↓
🔐 Enter credentials (or 2FA via authenticator)
↓
❌ Invalid → show error
after 5 attempts → lock 15min
✅ Valid → JWT issued
redirect to /admin/dashboard
↓
📊 Dashboard loads with KPIs
↓
👥 Users → CRUD operations
Search, filter, edit, suspend, delete
📚 Content → Manage
Add/edit questions, videos, essays
📈 Analytics → Reports
View metrics, export PDF/CSV
↓
💾 Every change writes to audit log
(actor, action, timestamp, IP, before/after)
↓
🎯 END — Admin logs out (auto after 30min idle)
Flow Specs: Authentication: Firebase Auth + custom claims for roles · Session: 30min idle timeout, max 8h absolute · 2FA: TOTP (Google Authenticator) for super admins · Audit log: immutable Firestore collection, archived monthly · Permission tiers: Super Admin (all), Editor (content only), Moderator (users only), Viewer (read-only analytics)
