Sample Step-by-Step Solution

Here's how we break down a real WAEC Mathematics question:

WAEC 2023 — Mathematics

Solve for x: 2x² − 5x − 3 = 0

1
Identify the equation type: Quadratic in standard form ax² + bx + c = 0, where a=2, b=−5, c=−3.
2
Choose method — Factorization: Two numbers whose product is a×c = −6, sum is b = −5: −6 and +1.
3
Split middle term: 2x² − 6x + x − 3 = 0
4
Group and factor: 2x(x−3) + 1(x−3) = 0 → (2x+1)(x−3) = 0
5
Apply zero product: x = −½ or x = 3
✅ Final Answer: x = −½ or x = 3
